# رفيق الماء لويندوز

شخصية تمشي من يسار شاشة ويندوز إلى المنتصف لتذكيرك بشرب الماء. الكود مكتوب بلغة Python ويستخدم PySide6.

## التشغيل

1. ثبّت Python على ويندوز مع تفعيل **Add Python to PATH**.
2. نزّل المستودع وشغّل `start.bat`؛ سيُثبّت PySide6 ويبدأ البرنامج بصورة القطوة المرفقة.
3. لتغيير القطوة، ضع صورتك الشفافة داخل مجلد `character` باسم `avatar.png`. للحركة، أضف صورًا شفافة باسم `walk_01.png` و`walk_02.png` وهكذا في المجلد نفسه. إن لم تضف صور حركة، سيستخدم صورة `avatar.png` أثناء المشي.

صورة القطوة فقط مرفوعة في `assets/cat.png`. الصور الشخصية غير مرفوعة في هذا المستودع؛ أي صورة تضيفها تبقى محليًا عندك.

اضغط أيقونة القطرة قرب الساعة لإظهار التذكير فورًا، أو اضغطها بزر الفأرة الأيمن لفتح الإعدادات والخروج. يبدأ أول تذكير بعد دقيقتين من تشغيل البرنامج، ويتجدد الانتظار بعد الرجوع من السكون. زر «لا توكل بعدين» يعيد التذكير بعد دقيقة، بينما زر «شربت ماء» يستخدم الفترة المحددة في الإعدادات.

`settings.json` وملفات `character` مستبعدة من Git، فكل شخص يضع صوره وإعداداته على جهازه.
